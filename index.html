Free order flow MCP server and API

Live order book depth and walls, candles with buy and sell volume and CVD, large trades, liquidations, an estimated liquidation map, funding, open interest and key price levels for nine markets: Bitcoin, Ethereum, Solana, XRP, gold, silver, WTI crude oil, the US 500 and the US 100. No key, no account.

  • MCP server: https://swiftedge.uk/mcp (Streamable HTTP)
  • REST API: https://swiftedge.uk/api/v1/... (JSON)
  • OpenAPI 3.1: /api/v1/openapi.json, which also works as a ChatGPT GPT action
  • Official MCP Registry: listed as uk.swiftedge/orderflow

Connect it to your AI app

Claude (claude.ai or the desktop app): Settings → Connectors → Add custom connector, and paste https://swiftedge.uk/mcp.

Claude Code:

claude mcp add --transport http swiftedge https://swiftedge.uk/mcp

Cursor and other clients with an mcp.json:

{ "mcpServers": { "swiftedge": { "url": "https://swiftedge.uk/mcp" } } }

ChatGPT: import openapi.json as a GPT action.

Then ask, for example: "Where are the biggest bid walls on gold right now?", "Show me Bitcoin's CVD on the 4-hour chart" or "Where would longs on silver get liquidated?"

Good to know

Free, no key. Please link to swiftedge.uk when you show the data, for example under a chart or in a bot's reply.

Freshness. A snapshot is at most about 15 seconds old, the order book about 10 seconds and the liquidation map about 5 minutes. Responses are cached for 15 seconds.

What the numbers are. Swiftedge's own calculations on public perpetual futures order books and trades. Positioning levels and the liquidation map are estimates, not measurements and not a forecast. The data is descriptive and places no orders.

Live chart. For tick-by-tick data, open the live heatmap. You can also paper trade on the live order book.
